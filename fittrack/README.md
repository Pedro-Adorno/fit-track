# FitTrack
Local: `npm install && npm run dev`. Build: `npm run build`. Vercel: importe a pasta (preset Vite, `vercel.json` já incluso).
Dados ficam no LocalStorage de cada navegador (sem sincronização); use Perfil > Exportar backup para levar dados a outro aparelho.

## Limitações conhecidas
Sem PWA, sem fotos de progresso, sem notificações com o app fechado (sem backend). Sessão de treino em andamento não sobrevive a recarregar a página.
